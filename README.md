# Pratik Portfolio

A responsive personal portfolio website built with:
- HTML
- CSS
- JavaScript

## GitHub upload
Upload these files to your `pratik-portfolio` repository:
- `index.html`
- `style.css`
- `script.js`

Then enable GitHub Pages from the repository settings if you want a public website.

Before publishing, replace `your-email@example.com` and the placeholder project links with your real links.
